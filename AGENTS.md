# Protocolo Multi-Agente: Campuslands IA Academy

Este repositorio forma parte del ecosistema educativo de Campuslands. Es mantenido colaborativamente por Antigravity, Codex y Claude Code, compartiendo memoria continua en Obsidian y grafos de conocimiento con Graphify.

## Directivas del Proyecto
1. **Público Objetivo**: Campers y estudiantes de Campuslands que finalizan el módulo de JavaScript.
2. **Filosofía**: Código claro, accesible, sin capas innecesarias de complejidad ni dependencias pesadas de build.
3. **Identidad Visual**: Paleta corporativa oficial de Campuslands:
   - Violeta Eléctrico: `#5E3AE2`
   - Azul Profundo: `#000087` / `#08172E`
   - Celeste Vivo: `#2CAAFF`
   - Amarillo Acento: `#F4B422`
   - Verde Esmeralda: `#00AA80`
   - Tipografías: Plus Jakarta Sans y JetBrains Mono.
4. **Flujo de Git**:
   - `main`: Producción y GitHub Pages.
   - `dev`: Rama de integración y pruebas.
   - `feature/*`: Ramas de trabajo para nuevas funcionalidades o ejercicios.
