# Directivas para Claude Code: Campuslands IA Academy

## Stack y Normas
- **Proyecto**: `campuslands-ia-embeddings-chat-javascript`
- **Tecnologías**: HTML5, Tailwind CSS (CDN), Vanilla JavaScript moderno.
- **Regla de Oro**: Mantener el código simple y pedagógico. Evitar dependencias que requieran npm para correr en computadoras de laboratorio.
- **Sincronización**: Al realizar cambios en el código, ejecutar `graphify update .` y registrar avances en la memoria de Obsidian.
