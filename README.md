# 🚀 Campuslands · Laboratorio Interactivo de IA: Embeddings, Transformers y Chatbot en JavaScript

Bienvenido al laboratorio práctico e interactivo de Inteligencia Artificial para estudiantes de **Campuslands**.

Este proyecto está diseñado para que los campers dominen los pilares de la IA generativa de forma visual, concisa e interactiva:
1. **La Chispa de la IA**: Cómo funcionan realmente los modelos de lenguaje (probabilidad y matemáticas).
2. **Embeddings 2D Interactivos**: Comprender cómo las computadoras traducen palabras en coordenadas espaciales y cómo se relacionan entre sí.
3. **Transformers & Mecanismo de Atención**: Ver en tiempo real qué palabras se "prestan atención" mutuamente en una oración.
4. **Taller Paso a Paso (Tu Chat en JavaScript)**: Construcción completa de un chatbot web interactivo guiado con la ayuda de ChatGPT.
5. **Playground en Vivo**: Prueba tu bot en modo simulado o conéctalo a la API de OpenAI.

---

## 💻 Cómo Ejecutar el Proyecto
Este proyecto está hecho en **JavaScript puro**, HTML5 y Tailwind CSS. No requiere instalación de paquetes:
1. Clona el repositorio:
   ```bash
   git clone https://github.com/anndreloopez012/campuslands-ia-embeddings-chat-javascript.git
   ```
2. Abre `index.html` en tu navegador favorito o usa la extensión *Live Server* en VS Code.
3. ¡También puedes verlo en vivo en **GitHub Pages**: [https://anndreloopez012.github.io/campuslands-ia-embeddings-chat-javascript/](https://anndreloopez012.github.io/campuslands-ia-embeddings-chat-javascript/)!
