La IA no es magia: es Probabilidad y Código

Bienvenido al laboratorio, camper. Antes de tocar una sola API, necesitas entender la verdad fundamental: los modelos de lenguaje (LLMs como ChatGPT) no tienen conciencia ni piensan como humanos. Son colosales calculadoras estadísticas que predicen qué palabra tiene mayor probabilidad matemática de aparecer a continuación.

La Realidad del Programador

Lo que realmente hace el algoritmo

"Un LLM es una red neuronal gigante que toma una secuencia de números (tokens), analiza las relaciones contextuales (atención) y calcula una distribución de probabilidades para el siguiente número."

El poder del camper: Al entender cómo procesa los tokens, puedes diseñar prompts precisos, estructurar respuestas en JSON y conectarlo a tu código en JavaScript.

🔄 ¿Cómo se genera una respuesta? El ciclo paso a paso

Cada vez que el chat responde, se ejecuta este bucle iterativo milisegundo a milisegundo:

Paso 01

1. Tokenización

Tu texto se corta en pedacitos llamados tokens (palabras o sílabas).

"Hola mundo" → [9906, 1917]
Paso 02

2. Embeddings

Cada token se convierte en una lista de números (vector) que representa su significado.

9906 → [0.12, -0.45, 0.88...]
Paso 03

3. Atención (Transformer)

Todas las palabras se analizan juntas para entender qué rol juega cada una en la frase.

Calcula pesos de atención
Paso 04

4. Predicción del Siguiente

Elige el token con mayor probabilidad y lo añade a la frase para predecir el siguiente.

P("!") = 94.2% → Escribe "!"
🧭 Módulo 2

Embeddings: ¿Cómo las computadoras entienden significados?

Las computadoras no entienden letras ni sentimientos: solo procesan números. Un Embedding es la traducción de una palabra, frase o código a una lista de números llamada vector de coordenadas. La magia radica en que conceptos con significados similares terminan con números similares, ubicándose cerca en el espacio geométrico.

📍
La analogía del GPS: En Google Maps, dos lugares cercanos (como dos aulas de Campuslands) tienen coordenadas de latitud y longitud muy parecidas. Con los Embeddings pasa lo mismo: las palabras "gato" y "perro" tienen coordenadas casi idénticas, mientras que "refrigerador" está a kilómetros de distancia.

⚡ Módulo 3

Transformers: La Revolución del Mecanismo de Atención

Antes del año 2017, las inteligencias artificiales leían los textos palabra por palabra en fila india (usando redes recurrentes RNNs). Era lento y para cuando llegaban al final de un párrafo largo, ya habían "olvidado" el inicio.

La arquitectura Transformer cambió la historia con una idea brillante: procesar todo el texto en paralelo a la vez y usar un Mecanismo de Atención ("Self-Attention") para determinar qué palabras deben prestarle atención a cuáles.

🔬 Inspector de Atención en Vivo

Haz clic o pasa el cursor sobre las palabras de la oración para ver a qué otras palabras le presta más "atención" matemática la IA para desambiguar el significado.

Foco de Atención Actual: "este"

Cuando el modelo llega a la palabra "este", el mecanismo de atención asigna el 72% de sus pesos a conectar con "bot" y el 18% con "código". Así sabe que el sujeto que tenía el error era el bot y no la computadora ni el camper.

⏳ Antes: Modelos Recurrentes (RNN/LSTM)

Lectura estrictamente secuencial: Palabra 1 → Palabra 2 → Palabra 3. Imposible de entrenar rápido en GPUs modernas y con memoria frágil.

⚡ Ahora: Arquitectura Transformer

Todas las palabras entran a la GPU al mismo tiempo. La matriz de atención conecta cada token con todos los demás en paralelo.

Paso 3 de 5

La Memoria de la IA: El Array de Mensajes

Las APIs de chat no tienen memoria propia. En cada llamada, debemos enviar toda la conversación previa dentro de un Array de objetos. Cada objeto tiene 2 propiedades clave: role y content.

role: "system"

Las reglas maestras del bot (ej: "Eres un tutor amigable de Campuslands y respondes breve").

role: "user"

Los mensajes que escribe el estudiante o usuario en el input.

role: "assistant"

Las respuestas que la IA devuelve y que agregamos al historial.

// Array que guarda la conversación completa
const historial = [
  {
    role: "system",
    content: "Eres el Tutor Virtual de Campuslands. Ayudas a los campers con explicaciones concisas y ejemplos en JavaScript."
  }
];

// Cuando el usuario escribe algo:
function agregarMensajeUsuario(texto) {
  historial.push({ role: "user", content: texto });
}

// Cuando la IA responde:
function agregarMensajeIA(textoRespuesta) {
  historial.push({ role: "assistant", content: textoRespuesta });
}
Paso 4 de 5

La Función de Envío con fetch() y async/await

Aquí usamos lo aprendido en JavaScript: una función asíncrona que hace una petición HTTP tipo POST al endpoint de Chat Completions: 

async function consultarChatGPT(apiKey, mensajes) {
  try {
    const respuesta = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${apiKey}`
      },
      body: JSON.stringify({
        model: "gpt-4o-mini", // Modelo rápido y económico
        messages: mensajes,
        temperature: 0.7
      })
    });

    if (!respuesta.ok) {
      throw new Error(`Error en la API: ${respuesta.status}`);
    }

    const data = await respuesta.json();
    // Extraemos el texto de la respuesta
    const contenidoIA = data.choices[0].message.content;
    return contenidoIA;

  } catch (error) {
    console.error("Hubo un fallo:", error);
    return "Lo siento camper, ocurrió un error al comunicarme con la IA.";
  }
}
Paso 5 de 5

Renderizado Dinámico en el DOM

Finalmente, conectamos el formulario para capturar el submit, pintar la burbuja del usuario y luego la del bot: 

const chatForm = document.getElementById("chat-form");
const userInput = document.getElementById("user-input");
const chatMessages = document.getElementById("chat-messages");

function renderBurbuja(texto, rol) {
  const burbuja = document.createElement("div");
  burbuja.className = `p-3 rounded-xl mb-3 text-xs leading-relaxed max-w-[80%] ${
    rol === "user" 
      ? "ml-auto bg-[#5E3AE2] text-white" 
      : "mr-auto bg-[#0D1E38] border border-[#1E355B] text-slate-200"
  }`;
  burbuja.textContent = texto;
  chatMessages.appendChild(burbuja);
  chatMessages.scrollTop = chatMessages.scrollHeight; // Auto-scroll
}

chatForm.addEventListener("submit", async (e) => {
  e.preventDefault();
  const mensaje = userInput.value.trim();
  if (!mensaje) return;

  // 1. Mostrar burbuja de usuario y limpiar input
  renderBurbuja(mensaje, "user");
  userInput.value = "";
  agregarMensajeUsuario(mensaje);

  // 2. Consultar y mostrar respuesta
  const respuesta = await consultarChatGPT("TU_API_KEY", historial);
  renderBurbuja(respuesta, "assistant");
  agregarMensajeIA(respuesta);
});
